# Project Structure

This repository contains the files required for the Retail Sales Data Analytics project.

## Folders and Files

* `README.md`: Provides an overview of the project, its objectives, and tools.
* `data/`: Stores the retail sales dataset.
* `notebooks/`: Will contain Python notebooks for data analysis, if used.
* `visualizations/`: Will contain charts and graphs created during the analysis.
* `dashboard/`: Will contain Power BI dashboard files.
* `report/`: Will contain the final project report.

## Purpose

This structure keeps the project organized and makes its files easier to understand and maintain.
