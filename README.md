# retail-sales-data-analytics
Retail Sales Analysis and Interactive Power BI Dashboard
## Project Overview

This project focuses on analysing retail sales data to identify sales trends, product performance, and useful business insights.

### Objectives

* Explore and understand the retail sales dataset.
* Calculate important sales statistics.
* Identify patterns in product sales.
* Create visualizations to communicate insights.
* Develop a Power BI dashboard to support data-driven decisions.

### Tools and Technologies

* Git and GitHub
* Microsoft Excel
* Python
* Power BI
